# Character references

Add your own images here before running:

- `protagonist.png`: character A, connected to `images.image_1`.
- `creature.png`: character B, connected to `images.image_2`.

Alternatively, set other paths/formats in `config.local.yaml`. Paths may be
absolute or relative to that YAML file. PNG, JPEG, and WebP supported by your
ComfyUI installation are suitable. No reference images were supplied with this
repository setup; there are deliberately no fake character placeholders.

Keep references focused on the intended character. The output scene can change
their poses while the prompt asks Qwen to retain their recognizable identities.
